## What PitchVault Does

PitchVault provides a browser-friendly workspace for maintaining football and soccer match recordings. It converts recorded content and its related information into organized archive entries that can be located, inspected, and exported more easily.

The application uses a web-oriented approach, with Express and HTML identified in the extracted metadata. This provides a practical foundation for cataloging match videos, applying tags to match details, and preparing archive data for later use.
